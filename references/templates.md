```
单元主题：_________
核心驱动问题：_________
课文性质定位：_________（见预解析表）

【教学要求】
1. 语块教学：按以下功能分类组织语块——_________（列出重点类别及语块）
2. 任务链设计：按"学习理解→应用实践→迁移创新"三阶段设计5步任务链
3. 读写结合路径：从_________课文提取语块，过渡到_________写作任务
4. 分层支架：提供初阶（填空仿写）、中阶（改写迁移）、高阶（独立创作）三层
5. 嵌入式评价：提供四维评价量表（内容完整/语言迁移/结构清晰/文化意义）

【学情信息】
基础薄弱学生占比约_________%，主要困难：_________

【写作任务】
体裁：_________  话题：_________  字数要求：_________词

【特别注意】
- 任务之间必须有逻辑衔接，不是独立活动的堆砌
- 必须包含"口头内化"环节（从读到写的过渡）
- 分层任务使用同一话题不同支撑程度，不是不同题目
- 每课时设计1-2个核心驱动问题统摄全课
- 评价要镶嵌在教学过程中，不是只在课后
```

## 五、人工优化检查清单

AI 生成教案后，逐项校验：

| 检查维度 | 检查内容 | 常见AI问题 |
|----------|----------|-----------|
| **逻辑连贯** | 任务链是否一脉相承？各环节是否有自然过渡？ | 活动各自独立，缺乏串联逻辑 |
| **核心问题** | 全课是否有1-2个驱动问题统摄？ | 只有活动没有问题 |
| **语块分类** | 语块功能分类是否正确？是否有遗漏？ | 分类错误，遗漏高频搭配 |
| **读写过渡** | 从读到写是否有"口头内化"台阶？ | 直接从读到写，跳过口头环节 |
| **真实场景** | 活动场景是否贴近学生生活？ | 活动为练句型而设计，脱离真实 |
| **分层匹配** | 支架程度是否匹配学情？ | 初阶不够简单，高阶不够开放 |
| **评价可操作** | 评价标准是否具体？反馈句式是否可用？ | 标准笼统，反馈书面化 |
| **思维培养** | 是否有分析、比较、评价类任务？ | 只有识别和描述类活动 |
| **三大目标** | 社会文化、思维认知、语言交流是否同时驱动？ | 只有语言目标 |
| **课文定位** | 每篇课文的性质是否明确标注？ | 面面俱到，缺乏取舍 |

## 六、教师备课检查清单

每份教案完成后，对照自查：

| 检查项 | 是/否 |
|--------|-------|
| ☐ 是否从课文中提取了可迁移语块（而非只教了词汇表） |
| ☐ 语块是否按表达功能分类（而非按字母顺序排列） |
| ☐ 是否设计了从"读"到"写"的完整任务链 |
| ☐ 任务链是否体现了"学习理解→应用实践→迁移创新"三个层次 |
| ☐ 是否有1-2个核心驱动问题统摄全课 |
| ☐ 是否为不同水平学生提供了分层支架 |
| ☐ 写作任务是否有明确的语块和句型支撑 |
| ☐ 评价是否镶嵌在教学过程中（而非只在课后） |
| ☐ 评价标准是否具体可操作（而非笼统的"好/不好"） |
| ☐ 教学目标是否指向核心素养四个维度 |
| ☐ 是否连接了学生的真实生活和文化经验 |
| ☐ 是否有思维培养的显性设计（分析/比较/评价类任务） |
| ☐ AI 生成内容是否经过专业校验（对照80/20质量法则） |

## 七、标准化流程："教材预解析 + AI 生成 + 人工优化"

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│              │     │              │     │              │
│  步骤1       │     │  步骤2       │     │  步骤3       │
│  教材内容    │ ──→ │  AI 生成     │ ──→ │  人工优化    │
│  预解析      │     │  教案初稿    │     │  定稿        │
│  (教师主导)  │     │  (AI 执行)   │     │  (教师干预)  │
│              │     │              │     │              │
└──────────────┘     └──────────────┘     └──────────────┘
   耗时: 15-20min      耗时: 2-3min         耗时: 15-20min
   产出: 预解析表       产出: 教案初稿       产出: 可用教案
```

步骤1（教师主导）：填写预解析表 → 明确课文性质 → 提取核心语块 → 设计核心问题 → 确定读写结合路径

步骤2（AI 执行）：输入预解析结果 + 单元信息 + 学情数据 → AI 生成完整教案框架

步骤3（教师干预）：校验任务链逻辑 → 补充核心问题和过渡活动 → 调整分层支架匹配学情 → 校准评价标准

## 八、写作评价四维量表模板

### 说明文评价量表

| 评价维度 | 4分（优秀） | 3分（良好） | 2分（待改进） |
|----------|------------|------------|--------------|
| **内容完整** | 五问信息完整，体现特色 | 信息基本完整，少量缺漏 | 信息零散，读者难以理解 |
| **语言迁移** | 自然使用单元语块和句型 | 使用部分语块，个别不准确 | 单词堆砌，语块较少 |
| **结构清晰** | 顺序合理，连接词恰当 | 顺序基本清楚 | 缺少组织，跳跃明显 |
| **文化意义** | 能说明为什么特别 | 有简单评价 | 只有个人喜好 |

### 记叙文评价量表

| 评价维度 | 4分（优秀） | 3分（良好） | 2分（待改进） |
|----------|------------|------------|--------------|
| **内容完整** | 起承转合完整，有高潮 | 故事基本完整 | 事件零散，缺少过程 |
| **语言迁移** | 自然使用时间标记和感受语块 | 使用部分语块 | 单词堆砌 |
| **结构清晰** | 时间线清楚，过渡自然 | 顺序基本清楚 | 时间混乱 |
| **意义反思** | 有深刻的感悟 | 有简单反思 | 没有感悟 |

### 应用文评价量表

| 评价维度 | 4分（优秀） | 3分（良好） | 2分（待改进） |
|----------|------------|------------|--------------|
| **内容完整** | 目的、信息、行动呼吁齐全 | 信息基本完整 | 信息不完整 |
| **语言迁移** | 自然使用应用文体式语块 | 使用部分语块 | 格式不规范 |
| **结构清晰** | 背景—主体—结尾层次清楚 | 层次基本清楚 | 层次混乱 |
| **语气得体** | 语气恰当，有感染力 | 语气基本得体 | 语气不当 |

## 九、教师反馈句式模板

| 类型 | 反馈句式 | 替代的笼统说法 |
|------|----------|---------------|
| 肯定 | "You told me WHEN the activity is clearly." | "Good!" |
| 建议 | "Try to add WHY you like it." | "写得不够好。" |
| 引导 | "Can you tell me more about what we can DO there?" | "再多写点。" |
| 深化 | "What makes this activity special for YOU?" | "要有个性。" |
