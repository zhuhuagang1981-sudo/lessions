# Task-Based Lesson Design Skill

基于龚亚夫「语块—句型—任务链」方法论的初中英语教案设计 WorkBuddy Skill，融合 2022 版新课标核心素养要求。

## 概述

本 Skill 封装了完整的任务型教学法教案设计工作流，核心是 **AI 协同五步闭环法**：

1. **文本研读** → 提取可迁移语言资源
2. **功能分类** → 建立语块—句型支架
3. **任务链设计** → 从输入到输出
4. **分层支架** → 支持不同水平学生
5. **嵌入式评价** → 贯穿教学全程

每一步明确「AI 做什么」和「教师干预什么」，遵循 80/20 质量法则。

## 五个设计转变

| 传统做法 | 本 Skill 做法 |
|----------|-------------|
| 教课文 | 用课文教表达 |
| 读写分离 | 读写闭环 |
| 教知识点 | 教语块—句型—任务链 |
| 统一标准 | 分层支架 |
| 纯人工设计 | AI 协同设计 |

## 核心方法论

- **六类功能语块框架**：定义命名、来源背景、组成材料、过程步骤、特征功能、评价意义
- **三阶段任务链**：学习理解 → 应用实践 → 迁移创新
- **五问支架法**：What → Where/When → What made of / What to do → What like → Why special
- **思维培养体系**：识别描述 → 分析比较 → 评价创造
- **80/20 质量法则**：AI 做好 80% 基础工作，教师干预 20% 关键判断

## 使用方式

### 作为 WorkBuddy Skill 使用

将本仓库克隆到 `~/.workbuddy/skills/` 目录下：

```bash
cd ~/.workbuddy/skills/
git clone https://github.com/zhuhuagang1981-sudo/lessions.git lesson-design-taskbased
```

之后在 WorkBuddy 中说「帮我出一份人教版八年级上册 Unit 3 的教案」即可自动触发。

### 触发词

- 教案设计、备课
- 任务型教案、读写结合
- 语块教学、语块—句型—任务链
- 人教版教案、初中英语教案
- 分层支架、嵌入式评价

### 示例对话

```
用户：帮我出一份初一人教版上册 Unit 8 "When is your birthday?" 的教案

AI：好的，我来按五步闭环法设计这份教案。

第一步：文本研读，提取语言资源
- 本单元主题：日期与生日表达
- 可迁移语块：...
- 课文性质定位：...

第二步：功能分类，建立语块—句型支架
...
```

## 适用教材

人教版初中英语（七年级至九年级），可扩展至其他采用任务型教学法的英语教材。
